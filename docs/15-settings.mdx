## Storage {#storage}

<GuideHtml html={"<div class=\"function-block\"><h3>About SD Card</h3><p>About SD Card displays the card’s filesystem, capacity, free space, and mount status.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → Settings → Storage → About SD Card</div><ol><li>Open About SD Card.</li><li>Use Left and Right through information pages when arrows appear.</li><li>Review filesystem, capacity, used/free space, and mount details shown.</li><li>Press Back.</li></ol></div><div class=\"function-block\"><h3>Format SD Card</h3><p>Format SD Card erases and prepares the microSD card for use by the M1.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → Settings → Storage → Format SD Card</div><ol><li>Back up every required file.</li><li>Leave USB Drive and stop captures or updates.</li><li>Open Format SD Card and read the warning.</li><li>Continue only if you want to erase everything on the card.</li><li>Keep power connected through format and remount.</li><li>Verify with About SD Card and the file browser.</li></ol><div class=\"callout warning\"><strong>Formatting erases the card</strong><p>Credentials, captures, dictionaries, databases, and update files will be lost.</p></div></div>"} />

## Power {#power}

<GuideHtml html={"<div class=\"function-block\"><h3>Battery Info</h3><p>Battery Info displays the M1’s current battery measurements and charging state.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → Settings → Power → Battery Info</div>Use Left and Right to move through the measurement pages. Record the displayed charge, voltage, current, temperature, health, or status fields. Back returns.</div><div class=\"function-block\"><h3>Reboot</h3><p>Reboot restarts the M1 without removing power.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → Settings → Power → Reboot</div><ol><li>Stop radio, storage, bridge, capture, and update operations.</li><li>Choose Reboot and confirm.</li><li>Wait for the home screen, then try the feature again.</li></ol></div><div class=\"function-block\"><h3>Power Off</h3><p>Power Off shuts the M1 down after active work has been stopped.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → Settings → Power → Power Off</div><ol><li>Stop writes and safely eject USB Drive.</li><li>Choose Power Off and confirm.</li><li>Wait for screen and indicators to turn off.</li><li>Use the documented power-on control to restart.</li></ol></div>"} />

## Firmware update {#firmware}

<GuideHtml html={"<div class=\"menu-path\"><strong>Menu path</strong>Main Menu → Settings → Firmware update</div><div class=\"function-block\"><h3>Image File</h3><p>Image File selects the STM32 firmware image that the M1 will install.</p><ol><li>Copy the approved STM32 image to its release-specified location.</li><li>Choose Image File, browse to the exact artifact, and press Center.</li><li>Verify the selected filename on return.</li></ol></div><div class=\"function-block\"><h3>Firmware update</h3><p>Firmware update validates and installs the selected STM32 image.</p><ol><li>Charge and connect stable USB power.</li><li>Choose Firmware update after verifying the image.</li><li>Do not remove power or card during validation, erase, write, or reboot.</li><li>After restart, verify Settings → About.</li></ol></div><div class=\"callout warning\"><strong>Matched release only</strong><p>Filename or build number alone does not prove hardware or regional compatibility. Verify the published checksum.</p></div>"} />

## ESP32 update {#esp32}

<GuideHtml html={"<div class=\"menu-path\"><strong>Menu path</strong>Main Menu → Settings → ESP32 update</div><div class=\"function-block\"><h3>Image File</h3><p>Image File selects the ESP32-C6 firmware image used by the wireless processor.</p>Select the exact ESP32-C6 image supplied with the release, never the STM32 image.</div><div class=\"function-block\"><h3>Start Address</h3><p>Start Address sets the flash location specified for the selected ESP32-C6 image.</p>Use Left and Right for the release-specified address. Do not guess from another product or build.</div><div class=\"function-block\"><h3>Firmware Update</h3><p>Firmware Update writes the selected image to the ESP32-C6 at the configured address.</p><ol><li>Confirm image, matching checksum/sidecar, and start address.</li><li>Connect stable power and leave Wi-Fi/Bluetooth.</li><li>Choose Firmware Update.</li><li>Keep power connected until completion.</li><li>Reboot and test Wi-Fi and Bluetooth.</li></ol></div><div class=\"callout warning\"><strong>Two processors</strong><p>STM32 and ESP32-C6 images are different. Updating one does not repair an incompatible image on the other.</p></div>"} />

## About {#about}

<GuideHtml html={"<p>About displays the M1 model, firmware version, build information, and identifiers used for support.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → Settings → About</div><ol><li>Open About.</li><li>Use Left and Right on Prev. and Next.</li><li>Record model, firmware/build label, and identifiers needed for support.</li><li>Press Back.</li></ol><p>For support, include screen name, build label, last action, storage state, and whether Wi-Fi, Bluetooth, USB Drive, or external hardware was active.</p>"} />

## Troubleshooting {#troubleshooting}

<GuideHtml html={"<div class=\"table-wrap\"><table><thead><tr><th>Problem</th><th>What to do</th></tr></thead><tbody><tr><td>SD info unavailable</td><td>Reinsert card, leave USB Drive, and reboot before formatting.</td></tr><tr><td>Format failed</td><td>Use stable power and a supported card; back up before computer repair.</td></tr><tr><td>Image refused</td><td>Verify the file type, size, checksum, and battery level.</td></tr><tr><td>ESP32 update fails</td><td>Verify image/address pair and retry only with the approved release set.</td></tr><tr><td>No reboot</td><td>Use the recovery guide; do not alter option bytes from unrelated instructions.</td></tr></tbody></table></div>"} />
