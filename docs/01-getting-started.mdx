## Before you begin {#before}

<GuideHtml html={"<p>Charge the M1 before a long session. Insert a compatible microSD card if you plan to save captures, credentials, card images, BLE records, or infrared data.</p><div class=\"callout warning\"><strong>Authorized use</strong><p>Use read, transmit, emulate, write, capture, network, USB, and GPIO functions only on equipment you own or are explicitly authorized to test.</p></div>"} />

## Physical controls {#controls}

<GuideHtml html={"<div class=\"table-wrap\"><table><thead><tr><th>Control</th><th>In menus</th><th>Inside a function</th></tr></thead><tbody><tr><td><span class=\"screen-key\">Up</span></td><td>Previous item.</td><td>Move through lists or change the selected value when shown.</td></tr><tr><td><span class=\"screen-key\">Down</span></td><td>Next item.</td><td>Move through lists, change a value, or use the action shown at the bottom of the screen.</td></tr><tr><td><span class=\"screen-key\">Left</span></td><td>Change a value where arrows appear.</td><td>Previous page/value, rescan, or the labeled lower-left action.</td></tr><tr><td><span class=\"screen-key\">Right</span></td><td>Change a value where arrows appear.</td><td>Next page/value, confirm, or the labeled lower-right action.</td></tr><tr><td><span class=\"screen-key\">Center</span></td><td>Open the highlighted item.</td><td>Start, stop, select, save, send, or run the labeled action.</td></tr><tr><td><span class=\"screen-key\">Back</span></td><td>Return one menu level.</td><td>Cancel, stop safely, or return to the preceding screen.</td></tr></tbody></table></div>"} />

## Use the virtual keyboard {#keyboard}

<GuideHtml html={"<ol><li>Use the directional buttons to move the cursor.</li><li>Press Center to enter the highlighted character.</li><li>Use the on-screen delete control to remove the previous character.</li><li>Choose Save only after checking the complete name or hexadecimal value.</li><li>Press Back to cancel without applying the entry.</li></ol><div class=\"callout note\"><strong>Hexadecimal fields</strong><p>Keys, passwords, UIDs, and GATT values require exact byte lengths. Use only 0–9 and A–F; an odd number of characters is not a complete byte.</p></div>"} />

## Use the file browser {#files}

<GuideHtml html={"<div class=\"menu-path\"><strong>Menu path</strong>Home → Left</div><ol><li>Press Left on the home screen.</li><li>Use Up and Down to select a folder or file.</li><li>Press Center to open it.</li><li>For a supported file, choose the available Run, Rename, or Delete action.</li><li>Check the filename before renaming or deleting it. Press Back to leave without changing the file.</li></ol><div class=\"callout warning\"><strong>Do not interrupt writes</strong><p>Do not remove the microSD card, disconnect USB, or power off during save, rename, delete, format, capture, or update operations.</p></div>"} />
