## Before you begin {#before-you-begin}

Your package should contain the **MonstaTek M1**, a **USB Type-C cable**, and a **quick-start guide**.

:::tip[Recommended first setup]
Charge the M1 before a long session. Insert a compatible microSD card if you plan to save captures, keep card libraries, or use the infrared database.
:::

## Power and controls {#power-and-controls}

| Control | Action |
| --- | --- |
| Power on | Press and hold **Center** for about three seconds. |
| Power off | Open **Settings > Power > Power Off**, then confirm. |
| Up / Down | Move through menus and vertical lists. |
| Center | Open the highlighted item, confirm a choice, or start the action shown on screen. |
| Left / Right | Change values or use the action shown on the current screen. |
| Back | Return to the previous screen or stop the current function. |

:::note[Home-screen shortcut]
From the home screen, press **Left** to open the microSD card file browser. This shortcut is separate from normal menu navigation.
:::

## Main menu {#main-menu}

The documented v0.8.x main-menu order is:

| Order | Feature |
| --- | --- |
| 1 | Sub-GHz |
| 2 | RFID (125 kHz) |
| 3 | NFC |
| 4 | Infrared |
| 5 | GPIO |
| 6 | Wi-Fi |
| 7 | Bluetooth |
| 8 | Settings |

## Your first session {#first-session}

1. Charge the M1 with a standard **5 V USB source**.
2. Insert and mount a compatible microSD card if you need saved files.
3. Check the official firmware release page before updating either processor.
4. Open **Features Overview**, then use the dedicated guide for the function you want to try.

:::warning[Responsible use]
Use radio, RFID, NFC, infrared, Wi-Fi, Bluetooth, USB, and GPIO functions only on systems and equipment you own or are authorized to test.
:::
