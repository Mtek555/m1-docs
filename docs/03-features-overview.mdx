## Radio and access tools {#radio-and-access-tools}

| Feature | What it does |
| --- | --- |
| NFC (13.56 MHz) | Detects supported cards and tags. Feature depth depends on the card family. |
| RFID (125 kHz) | Reads, saves, emulates, and writes supported low-frequency ID formats. Writing requires a compatible rewritable tag. |
| Sub-GHz | Records and replays supported sub-1 GHz signals and finds active frequencies. |
| Infrared | Learns supported remote commands, replays saved signals, and uses an optional database for universal remotes. |

## Wireless and expansion {#wireless-and-expansion}

| Feature | What it does |
| --- | --- |
| Wi-Fi | Uses the ESP32-C6 to scan nearby 2.4 GHz access points. |
| Bluetooth | Provides BLE scanning and advertising. |
| GPIO | Provides digital I/O, headers, a functional USB-UART bridge, and switchable 3.3 V or 5 V rails with a 0.5 A published limit. |
| USB | Provides charging, CDC serial, and microSD mass-storage access. |

## Which features need a microSD card? {#storage-requirements}

| Feature | Works without a card | Card required for |
| --- | --- | --- |
| NFC | Live detection and reading | Saving files and opening the Saved library |
| RFID | Live reading and immediate emulation | Saving files and opening the Saved library |
| Sub-GHz | Frequency Reader | Record and Replay |
| Infrared | Learning and direct replay may operate | Universal remote database and saved files |
| Wi-Fi / Bluetooth | Yes | Not required for scanning or advertising |
