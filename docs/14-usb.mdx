## Open USB Drive {#open}

<GuideHtml html={"<p>USB Drive presents the M1 microSD card to a connected computer as removable storage.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → USB → USB Drive</div><ol><li>Insert a microSD card and make sure the M1 recognizes it.</li><li>Connect a data-capable USB-C cable.</li><li>Open USB Drive.</li><li>Wait for the removable drive to appear.</li><li>Copy files into the matching feature folders.</li><li>Allow each copy to finish.</li></ol><div class=\"callout warning\"><strong>While USB Drive is open</strong><p>Do not remove the card, format it, power off, or start a function that writes to it.</p></div>"} />

## Disconnect safely {#disconnect}

<GuideHtml html={"<ol><li>Finish transfers and close open files.</li><li>Use Eject or Safely Remove on the computer.</li><li>Wait for the safe-removal message.</li><li>Press Back on M1.</li><li>Confirm the home file browser opens the card again.</li></ol>"} />
