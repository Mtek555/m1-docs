## USB functions {#usb-functions}

| Function | What it does |
| --- | --- |
| Charging | Powers the device and charges the internal battery from a standard 5 V source. |
| CDC virtual serial | Presents a serial interface for supported logs, commands, and serial communication. |
| MSC mass storage | Makes the microSD card available to a computer as a removable drive. |

## Use microSD mass storage {#usb-storage}

1. Open **Settings > Storage > Unmount SD Card**.
2. Connect the M1 with a data-capable USB-C cable.
3. Open the removable drive and copy the required files.
4. Eject the drive safely from the computer.
5. Disconnect USB or return to the M1, then open **Settings > Storage > Mount SD Card**.

:::danger[Avoid file corruption]
Do not remove the microSD card, disconnect USB, or remount the card while the computer is writing files.
:::

## CDC serial and the GPIO bridge {#cdc-and-bridge}

The M1 appears as a USB CDC virtual serial port. The functional **GPIO > USB-UART bridge** uses that USB serial connection to forward data bidirectionally to the selected UART target.

| Bridge target | Connection |
| --- | --- |
| UART: TX (PA9), RX (PA10), 3.3 V | External UART1 header connection |
| UART: ESP32 | Internal ESP32 UART connection |

:::note[Serial settings]
The default bridge setting is **115200 baud, 8 data bits, no parity, 1 stop bit**. Supported line-coding changes selected by the computer are applied to the active UART.
:::

## Troubleshooting {#usb-troubleshooting}

| Problem | What to try |
| --- | --- |
| M1 charges but no drive appears | Use a data cable and unmount the microSD card on the M1. |
| No serial port appears | Try another cable or port and check the operating-system device list or driver requirements. |
| Saved libraries fail after computer access | Eject the drive, disconnect USB, and mount the card again in Settings. |
| Files become corrupted | Avoid simultaneous M1/computer access and always eject before disconnecting. |
