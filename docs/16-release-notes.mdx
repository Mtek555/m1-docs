## Changes in this release {#menu-changes}

<GuideHtml html={"<div class=\"table-wrap\"><table><thead><tr><th>Area</th><th>Change</th></tr></thead><tbody><tr><td>USB</td><td>Added the top-level USB > USB Drive path for microSD mass-storage mode.</td></tr><tr><td>Sub-GHz</td><td>Scan, Record, Replay, Frequency Reader, and Remap Tx pin.</td></tr><tr><td>NFC</td><td>Read, Saved, Add, Extract Keys, and Tools with card-key dictionaries.</td></tr><tr><td>RFID</td><td>Added FDX-B pet-tag reading at 134.2 kHz under Utilities.</td></tr><tr><td>Infrared</td><td>Universal Remotes, Learn, Replay, and Remap Tx pin.</td></tr><tr><td>Wi-Fi</td><td>Networks, Deauth Client, MonstaShark, Handshake, Beacon, and Channel Survey.</td></tr><tr><td>Bluetooth</td><td>Scan Devices, Signal Meter, GATT Explorer, and Saved records.</td></tr><tr><td>Storage</td><td>The M1 creates its feature folders when the microSD card is ready.</td></tr></tbody></table></div>"} />

## Storage layout {#storage-layout}

<GuideHtml html={"<p>FW 0.8.0.5 uses these folders: <code>nfc/</code>, <code>nfc/system/</code>, <code>nfc/recover/</code>, <code>rfid/</code>, <code>subghz/</code>, <code>wifi/</code>, <code>ble/</code>, <code>infrared/</code>, and <code>infrared/db/</code>.</p>"} />

## Install FW 0.8.0.5 {#before-you-update}

<GuideHtml html={"<ul><li>Charge the M1 before starting.</li><li>Download FW 0.8.0.5 from the MonstaTek release page.</li><li>Copy the firmware file to the microSD card, then safely eject the USB drive from your computer.</li><li>Keep the M1 connected to USB power and leave the microSD card in place until the update finishes and the M1 restarts.</li><li>Open Settings > About and confirm that FW 0.8.0.5 appears.</li></ul>"} />
