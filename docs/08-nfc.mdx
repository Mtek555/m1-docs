<p className="guideLede">Read supported 13.56 MHz cards, use saved data, create profiles, recover MIFARE keys, and manage dictionaries.</p>

## Before you start {#before}

<GuideHtml html={"<div class=\"callout warning\"><strong>Sensitive card data</strong><p>NFC dumps, UIDs, keys, passwords, NDEF records, and transit data can be sensitive. Use only your cards or cards covered by explicit authorization.</p></div><p>Place one card flat against the NFC antenna area. Remove other contactless cards.</p>"} />

## Read {#read}

<GuideHtml html={"<p>Read detects an NFC card, identifies its family, and retrieves the information available for that card type.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → NFC → Read</div><ol><li>Place one card against the antenna.</li><li>Open Read and hold it still.</li><li>Keep the card still while the M1 reads its pages, blocks, sectors, or applications.</li><li>Review card family, UID, and completion state.</li><li>Press Center for the actions valid for this result.</li><li>Press Back to stop or return.</li></ol><div class=\"table-wrap\"><table><thead><tr><th>Action</th><th>When it appears and what to do</th></tr></thead><tbody><tr><td>Save</td><td>Usable result: name it and save under nfc/.</td></tr><tr><td>Save Partial</td><td>Incomplete MIFARE Classic data: save only if missing sectors are understood.</td></tr><tr><td>Emulate</td><td>Supported full data is available; present M1 to the authorized reader and press Back to stop.</td></tr><tr><td>Emulate UID</td><td>Only identity-level emulation is available.</td></tr><tr><td>Write</td><td>Compatible NTAG21x or MIFARE Classic result: align writable media and keep it still.</td></tr><tr><td>Unlock</td><td>Compatible protected Type 2 tag: follow the AUTHLIM precautions below.</td></tr><tr><td>Info</td><td>Open captured UID, NDEF, memory, sector, application, signature, or transit details.</td></tr></tbody></table></div><ul><li>A complete MIFARE Classic read covers every expected readable sector.</li><li>A partial result may contain UID and some sectors but is not a complete backup.</li><li>Type 2 and NTAG results can include pages, NDEF, signature, and protection state.</li><li>DESFire results expose card and discovered application information; protected content may remain unavailable.</li><li>Unknown cards may yield an identity without application data.</li></ul>"} />

## Saved {#saved}

<GuideHtml html={"<p>Saved opens NFC profiles stored on the microSD card and shows the actions supported by each profile.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → NFC → Saved</div><ol><li>Select a saved NFC file.</li><li>Review its family and UID.</li><li>Press Center for its applicable actions.</li><li>Use Emulate or Emulate UID exactly as labeled.</li><li>Use Edit UID only when changing stored identity is intentional.</li><li>Use Write or Unlock only when offered.</li><li>Open Info, or choose Rename or Delete to manage the file.</li></ol><div class=\"callout note\"><strong>Capability labels</strong><p>Emulate means the saved data supports the full-emulation path. Emulate UID means identity only.</p></div>"} />

## Add a card profile {#add}

<GuideHtml html={"<p>Add creates a new saved NFC profile using the memory layout and UID format of the selected card family.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → NFC → Add</div><div class=\"table-wrap\"><table><thead><tr><th>Item</th><th>What it creates</th></tr></thead><tbody><tr><td>MFC 1K</td><td>A MIFARE Classic 1K profile with an entered or generated UID.</td></tr><tr><td>MFC 4K</td><td>A MIFARE Classic 4K profile with an entered or generated UID.</td></tr><tr><td>Ultralight</td><td>A MIFARE Ultralight profile with an entered or generated UID.</td></tr><tr><td>NTAG213</td><td>An NTAG213 profile with the matching memory layout.</td></tr><tr><td>NTAG215</td><td>An NTAG215 profile with the matching memory layout.</td></tr><tr><td>NTAG216</td><td>An NTAG216 profile with the matching memory layout.</td></tr></tbody></table></div><ol><li>Select the exact profile.</li><li>Choose Enter UID for a known valid UID or Generate UID for a new identity.</li><li>Check every hexadecimal byte.</li><li>Press Center on Save.</li><li>Enter a unique filename.</li><li>Open the profile from Saved and review Info.</li></ol><div class=\"callout warning\"><strong>Profile is not application data</strong><p>Creating a profile does not copy protected keys, balances, permissions, or account access.</p></div>"} />

## Extract Keys {#extract}

<GuideHtml html={"<p>Extract Keys captures supported MIFARE Classic authentication exchanges for key-recovery work.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → NFC → Extract Keys</div><ol><li>Insert a writable microSD card.</li><li>Read the explanation and press Center on Start.</li><li>Hold the M1 near the reader while it captures the authentication exchange.</li><li>Wait for Authentication data captured, or press Back to stop.</li><li>Save the recovery artifact under nfc/recover/ when offered.</li><li>Use only recovered, validated keys in a later Read; a nonce capture does not guarantee a recovered key.</li></ol><div class=\"callout warning\"><strong>Protect recovery data</strong><p>Reader-authentication capture can expose access-control secrets. Obtain written authorization and handle files like passwords.</p></div>"} />

## Tools — MIFARE Classic Keys {#classic-keys}

<GuideHtml html={"<p>MIFARE Classic Keys manages the six-byte keys used automatically when reading Classic cards.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → NFC → Tools → MIFARE Classic Keys</div><ol><li>Review System and Your keys counts. System keys are read-only.</li><li>Press Center on Add.</li><li>Enter exactly 12 hexadecimal characters for the six-byte key.</li><li>Save; duplicate built-in or user keys are reported without another copy.</li><li>Press Right on List to browse the keys you added.</li><li>Select a user key and press Center.</li><li>Confirm Delete only for the intended user key.</li></ol><p>The combined dictionaries are used automatically during MIFARE Classic Read.</p>"} />

## Tools — Ultralight Keys {#ultralight-keys}

<GuideHtml html={"<p>Ultralight Keys manages 16-byte keys for supported MIFARE Ultralight C workflows.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → NFC → Tools → Ultralight Keys</div><ol><li>Review system and user counts.</li><li>Select Add Key.</li><li>Enter exactly 32 hexadecimal characters for the 16-byte Ultralight C key.</li><li>Save and verify the count.</li><li>Select Your Keys to browse the keys you added.</li><li>Press Center on Delete for the intended key.</li></ol><div class=\"callout note\"><strong>Key management</strong><p>Ultralight C keys can be stored, but full 3DES authentication may not be available during Read.</p></div>"} />

## Tools — NTAG/UL Passwords {#passwords}

<GuideHtml html={"<p>NTAG/UL Passwords manages four-byte passwords and PACK values used with compatible protected Type 2 tags.</p><div class=\"menu-path\"><strong>Menu path</strong>Main Menu → NFC → Tools → NTAG/UL Passwords</div><ol><li>Review system and user-password counts.</li><li>Select Add Password.</li><li>Enter the four-byte password as eight hexadecimal characters and provide PACK when requested.</li><li>Save and verify the count.</li><li>Open Your Passwords to browse owner entries.</li><li>Select and confirm Delete only for the intended password.</li></ol><p>The same dictionary is used by the compatible Type 2 Unlock workflow.</p>"} />

## Unlock a protected tag {#unlock}

<GuideHtml html={"<p>Unlock authenticates to a compatible protected Type 2 tag using a known password or an available dictionary.</p><ol><li>Read the compatible protected tag first.</li><li>Choose Unlock.</li><li>Select Enter Password for one known four-byte password. An incorrect attempt may consume the tag’s authentication limit.</li><li>Dictionary appears only when AUTHLIM is 0; otherwise it is hidden.</li><li>Keep the tag still during authentication and automatic re-read.</li><li>On Unlocked, press Center on View.</li><li>Press Back during a running attempt to cancel.</li></ol><div class=\"callout warning\"><strong>AUTHLIM</strong><p>Do not guess passwords on a limited authentication counter. Use one verified password or stop.</p></div>"} />

## Troubleshooting {#troubleshooting}

<GuideHtml html={"<div class=\"table-wrap\"><table><thead><tr><th>Problem</th><th>What to do</th></tr></thead><tbody><tr><td>Card not detected</td><td>Remove other cards, reposition, and keep the target still.</td></tr><tr><td>Classic read partial</td><td>Add authorized keys and read again.</td></tr><tr><td>Dictionary error</td><td>Check matching files under nfc/system/ and the card filesystem.</td></tr><tr><td>Write unavailable</td><td>The family or captured data is not eligible for the current write path.</td></tr><tr><td>Unlock missing</td><td>The tag is unsupported, not detected as protected, or lacks required protection data.</td></tr><tr><td>Password rejected</td><td>Stop before more attempts; verify PWD and PACK from an authorized source.</td></tr></tbody></table></div>"} />
