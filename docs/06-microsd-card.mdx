## Card requirements {#requirements}

<GuideHtml html={"<div class=\"table-wrap\"><table><thead><tr><th>Item</th><th>Supported</th></tr></thead><tbody><tr><td>Capacity</td><td>Up to 256 GB</td></tr><tr><td>Filesystem</td><td>FAT32 or exFAT</td></tr><tr><td>Use</td><td>Saved radio captures, NFC/RFID records, Wi-Fi/BLE records, infrared data, and update images</td></tr></tbody></table></div>"} />

## Folders created by the M1 {#folders}

<GuideHtml html={"<div class=\"table-wrap\"><table><thead><tr><th>Path</th><th>Contents</th></tr></thead><tbody><tr><td><code>nfc/</code></td><td>Saved NFC card profiles</td></tr><tr><td><code>nfc/system/</code></td><td>NFC key and password dictionaries</td></tr><tr><td><code>nfc/recover/</code></td><td>NFC recovery artifacts</td></tr><tr><td><code>rfid/</code></td><td>LF RFID records</td></tr><tr><td><code>subghz/</code></td><td>Sub-GHz captures</td></tr><tr><td><code>wifi/</code></td><td>Wi-Fi records and MonstaShark <code>.pcapng</code> files</td></tr><tr><td><code>ble/</code></td><td>Saved BLE advertisement records</td></tr><tr><td><code>infrared/</code></td><td>Learned IR signals</td></tr><tr><td><code>infrared/db/</code></td><td>Universal-remote database files</td></tr></tbody></table></div><div class=\"callout note\"><strong>Folders created automatically</strong><p>The firmware checks these folders when the card mounts. Existing folders are kept. If a file already uses a required folder name, the M1 leaves it unchanged and reports the problem.</p></div>"} />

## Browse files on the M1 {#browse}

<GuideHtml html={"<p>From the home screen, press Left. Open a folder with Center. Supported files may offer Delete, Rename, or Run actions. Back returns to the previous folder.</p>"} />

## USB Drive ownership {#usb-ownership}

<GuideHtml html={"<div class=\"callout warning\"><strong>One owner at a time</strong><p>While USB Drive is open, only the connected computer can access the microSD card. Do not remove the card or start a feature that needs it. Safely eject the drive on the computer before pressing Back or disconnecting.</p></div>"} />

## Troubleshooting {#troubleshooting}

<GuideHtml html={"<div class=\"table-wrap\"><table><thead><tr><th>Problem</th><th>What to try</th></tr></thead><tbody><tr><td>Card not detected</td><td>Reinsert the card, then reboot if needed.</td></tr><tr><td>Folder will not open</td><td>Check the filesystem on a computer and back up the card before repair.</td></tr><tr><td>Expected folder is missing</td><td>Exit USB Drive, then restart the M1 so it can create the missing folder.</td></tr><tr><td>Feature cannot save</td><td>Confirm free space, card mount state, and that the computer no longer owns the drive.</td></tr></tbody></table></div>"} />
