<p className="guideLede">Update the M1 or ESP32 firmware, then check that everything is working.</p>

## Choose the correct image {#choose-image}

<GuideHtml html={"<div class=\"callout note\"><strong>Verify the image</strong><p>Use the M1 firmware file provided by MonstaTek.</p></div><p>The M1 contains separate STM32 main firmware and ESP32-C6 wireless firmware. Each processor uses a different firmware file.</p>"} />

## Prepare the M1 {#prepare}

<GuideHtml html={"<ol><li>Back up the microSD card.</li><li>Charge the battery and connect stable USB power.</li><li>Copy the approved STM32 image to the microSD card.</li><li>Safely eject the USB drive before leaving USB Drive mode.</li><li>Exit Wi-Fi and Bluetooth before starting the update.</li></ol>"} />

## Update the STM32 firmware {#stm32-update}

<GuideHtml html={"<ol><li>Open Settings > Firmware update > Image File.</li><li>Select the approved STM32 image.</li><li>Return to Firmware update and confirm that the image is ready.</li><li>Choose Firmware update.</li><li>Do not remove power or the microSD card while the image is checked and written.</li><li>Allow the M1 to reboot, then open Settings > About and verify the build label.</li></ol><div class=\"callout note\"><strong>Dual-bank update</strong><p>The STM32 updater uses the M1 bootloader and two flash banks. If the update fails, follow the recovery guide for the next steps.</p></div>"} />

## Update the ESP32-C6 {#esp32-update}

<GuideHtml html={"<ol><li>Use the exact ESP32 image and matching MD5 sidecar supplied by MonstaTek.</li><li>Open Settings > ESP32 update > Image File and select the image.</li><li>Use the start address listed with the ESP32 firmware.</li><li>Choose Firmware Update and keep power connected until completion.</li><li>Restart the M1 and test both Wi-Fi and Bluetooth.</li></ol><div class=\"callout warning\"><strong>Separate compatibility</strong><p>An ESP32 update can leave Wi-Fi and Bluetooth unavailable even when the main M1 firmware still boots. Use the M1 and ESP32 firmware files provided together.</p></div>"} />

## If the update is refused {#update-errors}

<GuideHtml html={"<div class=\"table-wrap\"><table><thead><tr><th>Message or symptom</th><th>Check</th></tr></thead><tbody><tr><td>File access / type error</td><td>Confirm the card is mounted and the selected file is the correct image type.</td></tr><tr><td>Image size invalid</td><td>Download the firmware file again. Do not substitute or rename a different file.</td></tr><tr><td>CRC or MD5 mismatch</td><td>Stop. Re-copy or re-download the release files and compare checksums.</td></tr><tr><td>Low battery</td><td>Charge the M1 before retrying.</td></tr><tr><td>No reboot</td><td>Try the forced reboot, then use recovery only if normal update cannot complete.</td></tr></tbody></table></div>"} />
