## Current versions {#versions}

<GuideHtml html={"<div class=\"table-wrap\"><table><thead><tr><th>Component</th><th>Current version</th><th>What it controls</th></tr></thead><tbody><tr><td>M1 Firmware</td><td><strong>0.8.1.0</strong></td><td>The main M1 interface, storage, and device functions.</td></tr><tr><td>ESP32 Core</td><td><strong>1.0</strong></td><td>Wi-Fi and Bluetooth functions.</td></tr></tbody></table></div><div class=\"callout note\"><strong>Two components, two version numbers</strong><p>M1 Firmware and ESP32 Core are updated independently. Their version numbers are not expected to match. M1 Firmware 0.8.1.0 with ESP32 Core 1.0 is the current combination.</p></div>"} />

## Update with the M1 Web Manager {#web-manager}

<GuideHtml html={"<p>The <a href=\"https://control.monstatek.com\">M1 Web Manager</a> is the recommended way to update the M1.</p><ol><li>On a desktop computer, open a supported Chromium-based browser with Web Serial support.</li><li>Connect the M1 with a USB cable that supports data.</li><li>Open <a href=\"https://control.monstatek.com\">control.monstatek.com</a>.</li><li>Select Connect and choose the M1 serial connection.</li><li>Check M1 Firmware and ESP32 Core separately.</li><li>Select Update for each component that has an update available.</li><li>Keep the M1 connected until the update finishes and the device reconnects.</li><li>Confirm M1 Firmware 0.8.1.0 and ESP32 Core 1.0.</li><li>Use the database or content update in Web Manager when supported content is available.</li></ol><div class=\"callout note\"><strong>If you see Reinstall</strong><p>That component is already on the current version. Reinstall is available for troubleshooting; a normal update is not required.</p></div>"} />

## Update managed databases and content {#content}

<GuideHtml html={"<p>Web Manager can maintain supported system databases and content, including the infrared database. These managed files are separate from captures, credentials, and other files you create.</p><ul><li>A content update does not replace your saved captures or credentials.</li><li>Keep the M1 connected while files are transferred.</li><li>Do not open USB Drive during a Web Manager transfer.</li></ul>"} />

## One-time update for older firmware {#bootstrap}

<GuideHtml html={"<p>Firmware released before M1 Web Manager support does not contain the device-side update protocol required by Web Manager. Those devices need one SD-card update before Web Manager can manage later releases.</p><ol><li>Download the M1 firmware image published for the one-time bootstrap update.</li><li>Copy it to the microSD card using USB Drive or a card reader.</li><li>Safely eject the card or USB drive.</li><li>On the M1, open Settings → Firmware update → Image File and select the image.</li><li>Return to Firmware update and start the update.</li><li>Keep the M1 powered and leave the card inserted until it restarts.</li><li>After the M1 boots, reconnect it at <a href=\"https://control.monstatek.com\">control.monstatek.com</a> and use Web Manager for M1 Firmware, ESP32 Core, and managed content.</li></ol>"} />

## Troubleshooting {#troubleshooting}

<GuideHtml html={"<div class=\"table-wrap\"><table><thead><tr><th>Problem</th><th>What to do</th></tr></thead><tbody><tr><td>The browser cannot connect</td><td>Use a supported desktop Chromium browser, close other serial tools, reconnect the data cable, and try Connect again.</td></tr><tr><td>The M1 disconnects during update</td><td>Leave it connected. The device may restart and reconnect as part of the update.</td></tr><tr><td>Web Manager shows no supported update path</td><td>Your M1 may need the one-time SD-card bootstrap described above.</td></tr><tr><td>Wi-Fi or Bluetooth is unavailable afterward</td><td>Reconnect to Web Manager and confirm ESP32 Core 1.0 separately from M1 Firmware.</td></tr><tr><td>Update does not complete</td><td>Retry with a direct USB port and a known data cable. Use the recovery guide if the M1 no longer starts normally.</td></tr></tbody></table></div>"} />
